# wawie-local-agent-releases
Public Windows installers and checksums for Wawie Local Agent. Distribution files only.

## Falcon 1 (niche automobile v3)
`falcon1/falcon1-v3.tar.gz` : boîte à outils locale de Falcon 1 (tirage des variations, moteur son synthétisé, annexes). Somme SHA-256 dans `falcon1/falcon1-v3.tar.gz.sha256`.
```
mkdir -p ~/falcon1 && curl -fsSL https://raw.githubusercontent.com/geffred/wawie-local-agent-releases/main/falcon1/falcon1-v3.tar.gz | tar xz -C ~/falcon1
```
